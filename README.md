# Inscrição no Evento — API do IBGE

Atividade de Programação para Internet: formulário de inscrição com consulta de estados e cidades pela API do IBGE.

## Funcionalidades

- Carregamento dos estados e das cidades do estado escolhido.
- Pesquisa de cidades e exibição do total de cidades do estado.
- Validação dos campos e resumo da inscrição.
- Layout responsivo.

## Tecnologias

HTML, CSS e JavaScript.

## Como executar

Abra o arquivo `index.html` no navegador. É necessário acesso à internet para consultar a API do IBGE.

A inscrição é demonstrativa e não salva os dados.
